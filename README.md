# AlertyAI

AlertyAI is an AI-powered productivity app for task management and team collaboration.

## Get the App

For Android users, install AlertyAI directly from Google Play:

- Google Play Store: https://play.google.com/store/apps/details?id=com.alertyai.app
- Package name: com.alertyai.app
- Website: https://alertyai.com
- Product URL: https://com.alertyai.app

No web setup is required for users.

## Core Features

- Smart task planning with AI assistance
- Team collaboration with shared workflows
- Calendar-based scheduling and reminders
- Clean, mobile-first experience
